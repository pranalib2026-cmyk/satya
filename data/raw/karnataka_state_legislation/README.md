# Karnataka State Legislation

None of the 6 inspected external repositories contained primary Karnataka State Bare Acts.
Karnataka-specific legal materials collected from the approved datasets reside in:
- `data/raw/court_judgments/imljd/hc_karnataka.csv` (High Court of Karnataka CrPC 482 petitions, 2018-2024)
- `data/raw/government_notifications_and_circulars/gov_myscheme/gov_myscheme_data.json` (Karnataka state welfare schemes)

Official Karnataka state statutes must be sourced from `indiacode.nic.in` (Karnataka State repository) or `dpal.karnataka.gov.in`.
